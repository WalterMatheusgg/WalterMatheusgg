## 👨‍💻 Sobre mim

### Olá, seja bem-vindo ao meu universo de código! 🚀

Sou **Walter Matheus Soares da Silva**, Desenvolvedor Full Stack, com experiência na construção, manutenção e evolução de aplicações corporativas.

Minha especialidade é desenvolver soluções robustas no **Backend com Java e Spring Boot**, integradas a interfaces modernas utilizando **Angular, TypeScript e React**.

Tenho experiência com APIs REST, bancos de dados relacionais, arquitetura de aplicações, testes automatizados e integração entre sistemas.

- 🌱 Aprofundando conhecimentos em **arquitetura de software, microsserviços e cloud**.
- 💻 Stack principal: **Java 21, Spring Boot, Angular e TypeScript**.
- 🗄️ Bancos de dados: **Oracle, PostgreSQL e SQL Server**.
- 🎓 Formação em **Análise e Desenvolvimento de Sistemas**.
- 📚 MBA em **Engenharia de Software — em andamento**.
- 📍 Localização: **Brasília, DF — Brasil**.
- 💬 Pergunte-me sobre **Java, Spring Boot, Angular e APIs REST**.
- ⚡ Filosofia: *"Código limpo, soluções inteligentes e evolução contínua."*
